# Gallery visual identity

The Gallery icon combines stacked photo frames, a sun and landscape into a rounded G. Forest green and sage complement the application's warm ivory interface. The original transparent PNG is `web/public/brand/gallery-logo.png`; the interface uses the same image at sign-in and in the sidebar, and `web/index.html` uses it as the favicon. `Logo.vue` controls display sizing without modifying the raster asset.

Generation mode: built-in `image_gen` tool. No external image API, stock asset or API key was used.

## Generation prompt

Use case: logo-brand. Create a polished standalone app icon for Gallery, a calm privately hosted photo gallery whose interface uses sage green, warm ivory, rounded corners and minimal typography. Design a distinctive simple geometric monogram G formed by overlapping rounded photo frames with a small sun and subtle landscape cutout in negative space. Flat vector-like graphic, rich forest green and lighter sage, no gradients, no shadows, no texture, no lettering or wordmark, no mockup. Center one compact memorable mark with generous transparent padding on a genuinely transparent square background. Must read clearly as a tiny favicon and feel warm, refined, personal rather than corporate. Produce only the single finished icon.
